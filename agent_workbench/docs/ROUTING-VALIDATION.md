# 动态引导：阈值校准与保留验证

实验日期：2026-09-07。实验对象为克制型语义路由 `restrained-v1`；本报告汇总既有实验，不包含新一轮测试。

## 目标与实现

动态引导识别用户表达中的响应偏好，输出简洁、标准、深入或不注入。它不评估任务的客观难度，也不要求每条消息必须归类。

请求经过引用与代码过滤、滑动窗口切分后，由本地 multilingual-e5-small 生成归一化向量。用户窗口使用 `query:` 前缀，锚点示例使用 `passage:` 前缀。每档以 top-3 余弦相似度均值排序，同时检查最高分与前两档分差；未达阈值或合格窗口存在冲突时不注入。触发示例与引导正文分别配置，推理强度联动由独立开关控制。

## 实验协议

固定集合共 100 条，预先划分为 80 条校准用例和 20 条保留用例。校准集包含三档各 16 条正向用例及 32 条不注入用例；保留集包含三档各 4 条正向用例及 8 条不注入用例。

- 固定模型、示例、引导正文、解析规则、top-k、用例与标签，仅调整两项全局阈值。
- 相似度范围 0.520 至 0.960，步长 0.005；分差范围 0.000 至 0.050，步长 0.001，共 4,539 组组合。
- 首先要求校准集零负向误触发、零正向错档，再最大化正向正确触发数。同分时依次比较邻域最差表现、更高分差、更高相似度。
- 候选在读取保留集前锁定。使用生产 E5 对校准集复核，80/80 判决与缓存结果一致；此复核不是新增独立样本。
- 保留集在隔离的原生 WebView2 源码客户端执行一次，仅覆盖内存中的两项阈值。该实验不是安装版兼容性验收。

原始协议与选择记录见 [PROTOCOL.md](routing-evidence/PROTOCOL.md)、[selection.json](routing-evidence/selection.json)；完整搜索结果见 [grid.csv](routing-evidence/grid.csv)。

## 结果

| 指标 | 原参数校准集 | 候选校准集 | 候选保留集 |
| --- | ---: | ---: | ---: |
| 相似度 / 分差 | 0.520 / 0.030 | 0.835 / 0.013 | 0.835 / 0.013 |
| 简洁正确触发 | 0/16 | 7/16 | 1/4 |
| 标准正确触发 | 0/16 | 4/16 | 0/4 |
| 深入正确触发 | 7/16 | 14/16 | 4/4 |
| 正向正确触发 | 7/48 (14.58%) | 25/48 (52.08%) | 5/12 (41.67%) |
| 负向误触发 | 0/32 | 0/32 | 2/8 (25.00%) |
| 正向错档 | 0 | 0 | 0 |
| 正向未触发 | 41 | 23 | 7 |

正向正确触发以正向用例数为分母；负向误触发以预期不注入用例数为分母。保留集共触发 7 条，其中正确触发 5 条，触发精度为 5/7 (71.43%)。这些比例描述固定样本，不是总体性能估计。

保持相似度 0.835，仅将分差从 0.013 降至 0.012，校准集即出现 2 条误触发。因此，当前参数不能被描述为稳定的安全区间。

## 误触发分析

| 用例 | 原标签 | 实际结果 | 相似度 | 分差 |
| --- | --- | --- | ---: | ---: |
| N10：这个我还没决定。 | 不注入 | 简洁 | 0.892741 | 0.019917 |
| N20：把表头里的空格替换成下划线。 | 不注入 | 深入 | 0.870689 | 0.016042 |

N10 反映普通状态陈述与范围收敛锚点之间的语义重叠；N20 反映具体操作要求与深入偏好之间的混淆。两项阈值只能接受或拒绝排名结果，不能修正候选的语义排序。简洁与标准档的漏触发也说明当前锚点覆盖不足。

N10 的简洁响应在后续产品审阅中被认为可接受，但其原始负向标签未改变，仍计入 2/8 的误触发结果。没有为错误用例增加特判，也未根据保留集重新选参。

## 注入链路与运行检查

既有保留实验记录显示：20/20 输入与冻结集合一致，发送后输入框清空，响应正常结束，无超时或界面错误；20/20 路由模型就绪。命中时携带对应默认引导，未命中时不注入，推理强度保持本轮测试的手动 max 设置。这是测试配置，不是对特定提供方的产品强制策略。

20 个独立单轮会话的原始消息均被保留，数据库完整性检查通过。实验使用隔离数据目录，没有覆盖日常配置或安装目录。

## 验收与发布决定

事前标准要求保留集零误触发、零错档、无运行故障，且正向召回高于原校准基线。由于出现 2 条负向误触发，**本次实验未通过原验收标准**。

实验完成后，版本 0.4.13 采用 0.835 / 0.013 作为阶段性默认参数，以提高正向覆盖，同时保留允许不命中的行为。参数采用是产品取舍，不改变实验结论。原始统计中的 `product_defaults_updated=false` 与 `installer_rebuilt=false` 记录的是实验结束当时的状态；后续发布状态见 [0.4.13 发布记录](RELEASE-0.4.13.md)。
